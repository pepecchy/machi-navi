1.住民異動の手続きについて
(1)転入届(他市区町村から栃木市への引越し)
届出期間
栃木市に住み始めた日から14日以内
届出する人
世帯主または転入してきた人
必要なもの
1.転出証明書
前住所地の市区町村で発行されたもの
※マイナンバーカードに転出情報を登録して手続きをした場合は、転出証明書が発行されない場合があります。その場合の提出は、不要です。
2.本人確認書類
窓口にお越しになる方の運転免許証や健康保険証などの身分証明書
3.在留カード
外国籍の方は、必ずお持ちください。
4. マイナンバーカード
住民基本台帳カード
お持ちの方のみご用意ください。
※4桁の暗証番号が必要です。
※別世帯の代理人が手続きを行う場合、本人宛に照会文書を送付するため当日中に手続きが完了しません。
5.委任状
代理人に手続きを依頼する場合は必要です 。
備考
住居表示地区内に新築した建物へ転入する場合は、事前に 住居表示の付番の手続き が必要です。
(2)転入届(海外から栃木市への引越し)
日本人の場合
海外へ行く前に栃木市に住んでいた人
必要なもの
1.パスポート
2.マイナンバーカード
住民基本台帳カード
マイナンバーカードを申請希望の方は、窓口にお申し出ください。申請書をお渡しします。
3.委任状
代理人に手続きを依頼する場合は必要です 。
海外へ行く前は他市町村に住んでいた人
必要なもの
1.パスポート
2.戸籍謄本または抄本
本籍地が栃木市の方は不要です。
本籍地が栃木市以外の方は、取得方法を本籍地にご確認ください。
3. 戸籍の附票謄本または抄本
4.マイナンバーカード
住民基本台帳カード
マイナンバーカードを申請希望の方は、窓口にお申し出ください。申請書をお渡しします。
5.委任状
代理人に手続きを依頼する場合は必要です 。
外国人の場合
初めて日本に来た人
必要なもの
1.パスポート
2.在留カード
3.委任状
代理人に手続きを依頼する場合は必要です 。
日本に来るのは2回目以降の人
必要なもの
1.パスポート
2.在留カード
3 . 直近の日本での住所地がわかるもの
海外へ行く前の日本の住所地、海外への転出時期を申請書に記入していただきます。
4.マイナンバーカード
マイナンバーカードを申請希望の方は、窓口に申し出てください。申請書をお渡しします。
5.委任状
代理人に手続きを依頼する場合は必要です 。
(2)転居届(栃木市内での引越し)
届出期間
新しい住居に住み始めた日から14日以内
届出する人
世帯主または転居した人
必要なもの
1.本人確認書類
窓口にお越しになる方の運転免許証や健康保険証などの身分証明書
2.在留カード
外国籍の方は、必ずお持ちください。
3. マイナンバーカード
住民基本台帳カード
お持ちの方のみご用意ください。
※4桁の暗証番号が必要です。
※別世帯の代理人が手続きを行う場合、本人宛に照会文書を送付するため当日中に手続きが完了しません。
4.国民健康保険被保険者証
お持ちの方のみご用意ください。
5.後期高齢者医療被保険者証
6.介護保険被保険者証
7.こども医療費受給資格証
8.委任状
代理人に手続きを依頼する場合は必要です 。
備考
住居表示地区内に新築した建物へ転居する場合は、事前に 住居表示の付番の手続き が必要です。
(3)転出届(栃木市から他市区町村へ引越し)
届出期間
新しい住居に住み始める日の前後14日以内
届出する人
世帯主または転出する人
必要なもの
1.本人確認書類
窓口にお越しになる方の運転免許証や健康保険証などの身分証明書
2.印鑑登録カード
お持ちの方のみご用意ください。
お持ちの方のみご用意ください。
3.マイナンバーカード
住民基本台帳カード
4.国民健康保険被保険者証
5.後期高齢者医療被保険者証
6.介護保険被保険者証
7.こども医療費受給資格証
8.委任状
代理人に手続きを依頼する場合は必要です 。
マイナアプリや郵送で、窓口に行かずに転出のお手続きをすることもできます。
詳しくは、「 郵送やマイナアプリで転出の手続きができます 」をご覧ください。
(4)世帯変更届(世帯主の変更や世帯の分離、合併)
届出期間
変更があった日
届出する人
世帯主または変更のあった人
必要なもの
1.本人確認書類
窓口にお越しになる方のマイナンバーカードや運転免許証、健康保険証などの身分証明書
2.国民健康保険被保険者証
お持ちの方のみご用意ください。
3.こども医療費受給資格証
4.委任状
代理人に手続きを依頼する場合は必要です 。
